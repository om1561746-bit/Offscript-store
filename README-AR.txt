OFFSPCRIPT — STARTER STORE
==========================

المشروع ده بداية موقع متجر حقيقي بواجهة متجر وسلة مشتريات ونموذج Checkout.

مهم جداً:
- الدفع عند الاستلام: يجهز ملخص الطلب ويفتح WhatsApp لإرسال الطلب. لازم تضيف رقم WhatsApp الخاص بالبراند.
- الدفع بالبطاقة أونلاين: غير مفعّل في هذه النسخة. لا يتم تحصيل أي أموال. تفعيل الدفع يحتاج حساب تاجر لدى بوابة دفع متاحة في مصر (مثل Paymob أو غيرها)، ومفاتيح API، وBackend آمن للتحقق من الدفع. لا تضع مفاتيح سرية في ملفات الواجهة.
- الأسعار والمنتجات الحالية أمثلة فقط وليست أسعاراً حقيقية.
- الصور الحالية placeholders؛ أضف صور منتجاتك قبل الإطلاق.
- هذا الإصدار لا يخزن الطلبات في قاعدة بيانات أو لوحة إدارة. طلب COD يرسل تفاصيله عبر WhatsApp بعد ضغط العميل على إرسال الرسالة.

تعديل المنتجات:
افتح products.js وعدّل الاسم والسعر والتصنيف والمقاسات والصورة.
ضع الصور داخل مجلد images ثم اكتب مثلاً: image:"images/core-tee.jpg"

إعداد واتساب:
في app.js ابحث عن:
const wa=window.OFFSPCRIPT_WHATSAPP||"";
واستبدل window.OFFSPCRIPT_WHATSAPP برقم دولي بدون + أو مسافات، مثال توضيحي فقط:
const wa="201XXXXXXXXX";

النشر المجاني:
1) أنشئ حساب GitHub بمساعدة ولي أمرك إذا لزم.
2) أنشئ Repository وارفع الملفات.
3) من Settings > Pages اختر Deploy from a branch ثم main و /(root).
4) انتظر رابط GitHub Pages.
أو استخدم Cloudflare Pages واربطه بمستودع GitHub.

قبل استقبال طلبات حقيقية:
- استبدل المنتجات والأسعار والصور.
- أضف رقم واتساب صحيح.
- اختبر السلة والطلب من موبايل.
- فعّل بوابة الدفع أونلاين من خلال ولي أمرك/صاحب النشاط وبمساعدة مطور Backend.
- أضف سياسة الشحن والاستبدال والخصوصية وبيانات التواصل.
